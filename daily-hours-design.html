Scelte tecniche

Email: Resend vs SendGrid

Scelta: Resend.

CriterioResendSendGrid
IntegrazioneREST puro — un solo fetch(), nessun SDKSDK dedicato o REST verboso
Free tier3.000 email/mese, 100/giorno100/giorno (limite più stretto)
Setup dominioVerifica DNS semplice (5 min)Più passaggi, portale complesso
DXModerna, docs eccellentiEnterprise, over-engineered per questo uso
Compatibilità NetlifyPerfetta — usato in molti template ufficialiFunziona ma non nativo nell'ecosistema
Con 30–50 collaboratori, Resend free tier (3.000 email/mese) è più che sufficiente per ~22 giorni lavorativi × 50 persone = 1.100 email/mese.

Aggregazione: trigger SQL vs logica applicativa

Scelta: trigger PostgreSQL.

  • Atomicità garantita: il ricalcolo avviene nello stesso statement che inserisce i dati — nessuna finestra di incoerenza.
  • Idempotente: somma tutto da zero per quel mese, non tiene stato precedente.
  • Non dimenticabile: funziona indipendentemente da dove vengono inseriti i dati (API, psql diretto, future funzioni).
  • Logica applicativa: richiederebbe due round-trip (insert + update) e una transazione esplicita — più codice, più failure mode.

Token sicuro: JWT vs HMAC custom

Scelta: HMAC-SHA256 custom (nessuna dipendenza esterna).

  • Il progetto ha zero dipendenze extra — manteniamo questa filosofia.
  • Node.js crypto è built-in su Netlify (Node 18+).
  • Struttura: base64url(JSON{r,d,e}).hmac_hex — firmato, con scadenza, impossibile alterare risorsa o data senza invalidare la firma.
  • JWT richiederebbe jsonwebtoken o jose — dipendenze non necessarie.
Requisito: generare DAILY_TOKEN_SECRET con almeno 32 byte casuali. Usare: openssl rand -hex 32 o node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

Relazioni con tabelle esistenti

ore_mensili rimane invariata. Il trigger trg_sync_ore_mensili aggiorna automaticamente ore_q1 (giorni 1–15) e ore_q2 (giorni 16–fine mese) ogni volta che cambia un record in daily_hours. Le note (note_q1, note_q2) non vengono mai toccate dal trigger.

Logica di aggregazione

-- Esempio per settembre 2026, risorsa 42:
-- daily_hours: 1 sett=8, 2 sett=7, 15 sett=8, 16 sett=7, 30 sett=8
--
-- ore_q1 = 8 + 7 + 8          = 23   (giorni 1–15)
-- ore_q2 = 7 + 8              = 15   (giorni 16–30)
--
-- Se modifico il 1 sett da 8 a 6:
-- ore_q1 = 6 + 7 + 8          = 21   (ricalcolo completo da zero)

-- ═══════════════════════════════════════════════════════════════
--  Team Hours Tracker — Migration: Daily Hours Reminder
--  Eseguire UNA SOLA VOLTA sul database Neon
-- ═══════════════════════════════════════════════════════════════

-- 1. Tabella principale: ore giornaliere
CREATE TABLE IF NOT EXISTS daily_hours (
    id         BIGSERIAL PRIMARY KEY,
    risorsa_id INTEGER      NOT NULL REFERENCES risorse(id) ON DELETE CASCADE,
    data       DATE         NOT NULL,
    ore        NUMERIC(5,2) NOT NULL,
    created_at TIMESTAMP    DEFAULT NOW(),
    updated_at TIMESTAMP    DEFAULT NOW(),
    UNIQUE (risorsa_id, data)
);

-- 2. Funzione trigger: ricalcola ore_mensili da daily_hours
CREATE OR REPLACE FUNCTION sync_ore_mensili_from_daily()
RETURNS TRIGGER LANGUAGE plpgsql AS $$
DECLARE
    v_risorsa_id INTEGER;
    v_anno       INTEGER;
    v_mese       INTEGER;
    v_ore_q1     NUMERIC;
    v_ore_q2     NUMERIC;
BEGIN
    -- Per DELETE usa OLD; per INSERT/UPDATE usa NEW
    IF TG_OP = 'DELETE' THEN
        v_risorsa_id := OLD.risorsa_id;
        v_anno       := EXTRACT(YEAR  FROM OLD.data)::INTEGER;
        v_mese       := EXTRACT(MONTH FROM OLD.data)::INTEGER;
    ELSE
        v_risorsa_id := NEW.risorsa_id;
        v_anno       := EXTRACT(YEAR  FROM NEW.data)::INTEGER;
        v_mese       := EXTRACT(MONTH FROM NEW.data)::INTEGER;
    END IF;

    -- Ricalcolo aggregato completo (idempotente)
    SELECT
        COALESCE(SUM(CASE WHEN EXTRACT(DAY FROM data) <= 15 THEN ore ELSE 0 END), 0),
        COALESCE(SUM(CASE WHEN EXTRACT(DAY FROM data) >  15 THEN ore ELSE 0 END), 0)
    INTO v_ore_q1, v_ore_q2
    FROM daily_hours
    WHERE risorsa_id = v_risorsa_id
      AND EXTRACT(YEAR  FROM data) = v_anno
      AND EXTRACT(MONTH FROM data) = v_mese;

    -- Upsert in ore_mensili (NON tocca le note)
    INSERT INTO ore_mensili (risorsa_id, anno, mese, ore_q1, note_q1, ore_q2, note_q2)
    VALUES (v_risorsa_id, v_anno, v_mese, v_ore_q1, NULL, v_ore_q2, NULL)
    ON CONFLICT (risorsa_id, anno, mese)
    DO UPDATE SET
        ore_q1 = EXCLUDED.ore_q1,
        ore_q2 = EXCLUDED.ore_q2;
        -- note_q1 e note_q2 non vengono mai sovrascritte

    RETURN COALESCE(NEW, OLD);
END;
$$;

-- 3. Trigger (DROP + CREATE = idempotente)
DROP TRIGGER IF EXISTS trg_sync_ore_mensili ON daily_hours;
CREATE TRIGGER trg_sync_ore_mensili
AFTER INSERT OR UPDATE OR DELETE ON daily_hours
FOR EACH ROW EXECUTE FUNCTION sync_ore_mensili_from_daily();

-- Verifica
SELECT 'Migration completata' AS status;

netlify/functions/daily.mjs NUOVO

Gestisce le API token-based per i collaboratori. Nessun login richiesto — il token identifica utente e giorno.

netlify/functions/daily.mjs NUOVO FILE 
// ════════════════════════════════════════════════════════════════════════
//  daily.mjs — API token-based per registrazione ore giornaliere
//  Nessun login. Il token (HMAC-SHA256) identifica utente + giorno.
//  Endpoint: POST /api/daily  { action, payload }
//  Actions: getByToken, saveByToken
// ════════════════════════════════════════════════════════════════════════
import { neon }           from '@neondatabase/serverless';
import { createHmac, timingSafeEqual } from 'crypto';

const sql    = neon(process.env.DATABASE_URL);
const SECRET = process.env.DAILY_TOKEN_SECRET;

// ── Token: {r: risorsaId, d: 'YYYY-MM-DD', e: unixExpiry} ──────────────
function generateToken(risorsaId, data) {
  const exp = Math.floor(Date.now() / 1000) + 36 * 3600; // 36 ore
  const b64 = Buffer.from(JSON.stringify({ r: risorsaId, d: data, e: exp })).toString('base64url');
  const sig = createHmac('sha256', SECRET).update(b64).digest('hex');
  return `${b64}.${sig}`;
}

function verifyToken(token) {
  if (!SECRET) throw new Error('DAILY_TOKEN_SECRET non configurato');
  const dot = token.indexOf('.');
  if (dot < 1) throw new Error('Token malformato');
  const b64      = token.slice(0, dot);
  const sig      = token.slice(dot + 1);
  const expected = createHmac('sha256', SECRET).update(b64).digest('hex');
  let valid = false;
  try { valid = timingSafeEqual(Buffer.from(sig, 'hex'), Buffer.from(expected, 'hex')); } catch {}
  if (!valid) throw new Error('Firma token non valida');
  let payload;
  try { payload = JSON.parse(Buffer.from(b64, 'base64url').toString()); }
  catch { throw new Error('Payload token non valido'); }
  if (!payload.r || !payload.d || !payload.e) throw new Error('Token campi mancanti');
  if (Math.floor(Date.now() / 1000) > payload.e) throw new Error('Token scaduto');
  return payload; // { r: risorsaId, d: 'YYYY-MM-DD', e: exp }
}

// ── getByToken: valida token, restituisce risorsa + ore già inserite ───
async function getByToken(p) {
  const { r: risorsaId, d: data } = verifyToken(p.token);
  const [risorsa] = await sql`SELECT id, full_name FROM risorse WHERE id=${risorsaId}`;
  if (!risorsa) throw new Error('Risorsa non trovata');
  const [entry] = await sql`
    SELECT ore::float AS ore
    FROM daily_hours
    WHERE risorsa_id=${risorsaId} AND data=${data}::date`;
  return {
    risorsaId: +risorsa.id,
    data,
    fullName:  risorsa.full_name,
    ore:       entry != null ? entry.ore : null
  };
}

// ── saveByToken: upsert daily_hours → il trigger aggiorna ore_mensili ──
async function saveByToken(p) {
  const { r: risorsaId, d: data } = verifyToken(p.token);
  const ore = parseFloat(p.ore);
  if (isNaN(ore) || ore < 0 || ore > 24) throw new Error('Valore ore non valido (0–24)');
  const [row] = await sql`
    INSERT INTO daily_hours (risorsa_id, data, ore, updated_at)
    VALUES (${risorsaId}, ${data}::date, ${ore}, NOW())
    ON CONFLICT (risorsa_id, data)
    DO UPDATE SET ore=${ore}, updated_at=NOW()
    RETURNING id, ore::float AS ore`;
  return { id: row.id, ore: row.ore };
}

// ── routing ────────────────────────────────────────────────────────────
const ACTIONS = { getByToken, saveByToken };

export async function handler(event) {
  const headers = {
    'Content-Type': 'application/json',
    'Access-Control-Allow-Origin': '*'
  };
  if (event.httpMethod === 'OPTIONS') return { statusCode: 200, headers };
  if (event.httpMethod !== 'POST')
    return { statusCode: 405, headers, body: JSON.stringify({ error: 'Method Not Allowed' }) };

  let action, payload;
  try {
    const parsed = JSON.parse(event.body || '{}');
    action = parsed.action; payload = parsed.payload || {};
  } catch {
    return { statusCode: 400, headers, body: JSON.stringify({ error: 'Body JSON non valido' }) };
  }

  const fn = ACTIONS[action];
  if (!fn)
    return { statusCode: 400, headers, body: JSON.stringify({ error: `Action sconosciuta: ${action}` }) };

  try {
    const result = await fn(payload);
    return { statusCode: 200, headers, body: JSON.stringify({ ok: true, data: result }) };
  } catch (err) {
    const status = (err.message.includes('scaduto') || err.message.includes('firma')) ? 401 : 500;
    return { statusCode: status, headers, body: JSON.stringify({ error: err.message }) };
  }
}

netlify/functions/send-daily-reminder.mjs NUOVO

Funzione schedulata. Gira ogni giorno lavorativo alle 07:00 UTC (08:00 CET / 09:00 CEST). Genera token, invia email a tutte le risorse con indirizzo email registrato.

netlify/functions/send-daily-reminder.mjs NUOVO FILE 
// ════════════════════════════════════════════════════════════════════════
//  send-daily-reminder.mjs — Netlify Scheduled Function
//  Schedule: 0 7 * * 1-5  (07:00 UTC lun-ven)
//  Genera token HMAC + invia email Resend a ogni risorsa con email.
// ════════════════════════════════════════════════════════════════════════
import { neon }      from '@neondatabase/serverless';
import { createHmac } from 'crypto';

const sql          = neon(process.env.DATABASE_URL);
const SECRET       = process.env.DAILY_TOKEN_SECRET;
const SITE_URL     = (process.env.SITE_URL || '').replace(/\/$/, '');
const RESEND_KEY   = process.env.RESEND_API_KEY;
const FROM_EMAIL   = process.env.FROM_EMAIL   || 'noreply@example.com';
const FROM_NAME    = process.env.FROM_NAME    || 'Team Hours Tracker';

// ── genera token identico a daily.mjs (stesso algoritmo) ──
function generateToken(risorsaId, data) {
  const exp = Math.floor(Date.now() / 1000) + 36 * 3600;
  const b64 = Buffer.from(JSON.stringify({ r: risorsaId, d: data, e: exp })).toString('base64url');
  const sig = createHmac('sha256', SECRET).update(b64).digest('hex');
  return `${b64}.${sig}`;
}

// ── formatta data in italiano ──
function formatDateIT(iso) {
  const DAYS   = ['Domenica','Lunedì','Martedì','Mercoledì','Giovedì','Venerdì','Sabato'];
  const MONTHS = ['gennaio','febbraio','marzo','aprile','maggio','giugno',
                  'luglio','agosto','settembre','ottobre','novembre','dicembre'];
  const [y,m,d] = iso.split('-');
  const dt = new Date(`${iso}T12:00:00Z`);
  return `${DAYS[dt.getUTCDay()]} ${parseInt(d)} ${MONTHS[parseInt(m)-1]} ${y}`;
}

// ── invia email tramite Resend REST API ──
async function sendEmail(to, fullName, dataISO) {
  const token     = generateToken(fullName._id, dataISO); // passato dal chiamante
  const dateLabel = formatDateIT(dataISO);
  const firstName = fullName.full_name.split(' ')[0];
  const link      = `${SITE_URL}/daily-hours.html?token=${encodeURIComponent(token)}`;

  const res = await fetch('https://api.resend.com/emails', {
    method:  'POST',
    headers: { 'Authorization': `Bearer ${RESEND_KEY}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({
      from:    `${FROM_NAME} <${FROM_EMAIL}>`,
      to:      [to],
      subject: `Registra le tue ore — ${dateLabel}`,
      html:    buildEmailHtml(firstName, fullName.full_name, dateLabel, link)
    })
  });
  if (!res.ok) {
    const body = await res.text();
    throw new Error(`Resend ${res.status}: ${body}`);
  }
}

// ── handler principale (Netlify chiama questo ogni giorno lav.) ──
export const handler = async (event) => {
  const today = new Date();
  const dow   = today.getUTCDay(); // 0=dom, 6=sab
  if (dow === 0 || dow === 6) {
    console.log('Weekend — nessuna email');
    return { statusCode: 200, body: JSON.stringify({ ok: true, skipped: 'weekend' }) };
  }

  const dataISO = today.toISOString().split('T')[0]; // 'YYYY-MM-DD'
  console.log(`Invio reminder per ${dataISO}`);

  const risorse = await sql`
    SELECT id AS _id, full_name, email
    FROM risorse
    WHERE email IS NOT NULL AND email <> ''
    ORDER BY cognome, nome`;

  const results = { sent: 0, errors: [] };
  for (const r of risorse) {
    try {
      await sendEmail(r.email, r, dataISO);
      results.sent++;
      console.log(`✓ ${r.email}`);
    } catch (err) {
      console.error(`✗ ${r.email}: ${err.message}`);
      results.errors.push({ email: r.email, error: err.message });
    }
  }

  console.log(`Fine: ${results.sent} inviate, ${results.errors.length} errori`);
  return { statusCode: 200, body: JSON.stringify({ ok: true, ...results }) };
};

async function callApi(action, payload) {
  const r = await fetch(API, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ action, payload })
  });
  const json = await r.json();
  if (!json.ok) throw new Error(json.error || 'Errore sconosciuto');
  return json.data;
}

function fmtDate(iso) {
  const DAYS   = ['Domenica','Lunedì','Martedì','Mercoledì','Giovedì','Venerdì','Sabato'];
  const MONTHS = ['gennaio','febbraio','marzo','aprile','maggio','giugno',
                  'luglio','agosto','settembre','ottobre','novembre','dicembre'];
  const dt = new Date(`${iso}T12:00:00Z`);
  return `${DAYS[dt.getUTCDay()]} ${dt.getUTCDate()} ${MONTHS[dt.getUTCMonth()]} ${dt.getUTCFullYear()}`;
}

async function doSave() {
  const inp  = document.getElementById('ore-inp');
  const btn  = document.getElementById('save');
  const alrt = document.getElementById('alert');
  const bnr  = document.getElementById('banner');
  const ore  = parseFloat(inp.value);
  if (isNaN(ore) || ore < 0 || ore > 24) {
    alrt.className = 'alert err';
    alrt.textContent = '⚠ Inserisci un valore valido (0–24)';
    return;
  }
  btn.disabled = true; btn.textContent = 'Salvataggio...';
  alrt.className = 'alert';
  try {
    await callApi('saveByToken', { token: _token, ore });
    alrt.className = 'alert ok';
    alrt.textContent = `✓ ${ore} ore salvate!`;
    if (bnr) bnr.style.display = 'none';
  } catch (e) {
    alrt.className = 'alert err';
    alrt.textContent = '✗ ' + e.message;
  } finally {
    btn.disabled = false; btn.textContent = 'Salva';
  }
}

Setup step-by-step

  1. Crea account Resend su resend.com → verifica il dominio mittente (Settings → Domains). In fase di test, puoi usare onboarding@resend.dev per inviare solo alla tua email.
  2. Esegui la migration SQL su Neon Console → SQL Editor: incolla il contenuto di migration_daily_hours.sql e lancia. Verifica che stampi "Migration completata".
  3. Genera il secret: openssl rand -hex 32 → copia il risultato.
  4. Aggiungi le variabili d'ambiente su Netlify → Site Configuration → Environment Variables: DAILY_TOKEN_SECRET, RESEND_API_KEY, SITE_URL, FROM_EMAIL, FROM_NAME.
  5. Crea i 3 nuovi file nel progetto:
    • netlify/functions/daily.mjs
    • netlify/functions/send-daily-reminder.mjs
    • daily-hours.html
  6. Modifica netlify/functions/db.mjs: aggiungi la riga CREATE TABLE IF NOT EXISTS daily_hours nella funzione bootstrap().
  7. Modifica netlify.toml: aggiungi il redirect /api/daily e la configurazione della funzione schedulata.
  8. Deploy su Netlify (git push → auto-deploy). Verifica che tutte le funzioni appaiano nella tab Functions del sito.
  9. Test manuale: invoca send-daily-reminder manualmente dal pannello Netlify → Functions → send-daily-reminder → Test function. Controlla la casella email e clicca il link ricevuto.
  10. Verifica aggregazione: dopo aver salvato ore tramite il link, vai su Netlify DB o app principale e controlla che ore_mensili si sia aggiornata.

Edge case & gestione errori

ScenarioComportamento
Token scaduto (oltre 36h) Risposta HTTP 401, messaggio "Link scaduto. Attendi l'email di domani."
Token manomesso / firma errata Risposta HTTP 401. timingSafeEqual previene timing attacks.
Risorsa eliminata dopo emissione token getByToken lancia "Risorsa non trovata" — HTTP 500 con messaggio chiaro.
Ore già inserite, l'utente riapre il link Form pre-compilato con il valore esistente + banner "già registrate — puoi modificarle".
Utente riapre il link più volte ON CONFLICT DO UPDATE: ogni salvataggio sovrascrive il precedente, trigger ricalcola.
Ore = 0 (giornata non lavorata) Valore valido, salvato normalmente. Il trigger aggiorna ore_q1/q2 di conseguenza.
Ore > 24 Blocco lato client (input) + validazione backend — risposta 500 "Valore ore non valido".
Risorsa senza email La query del reminder filtra WHERE email IS NOT NULL AND email <> '' — saltata silenziosamente.
Email non recapitata (bounce) Log dell'errore in console Netlify, contatore errors[] nel response body. Funzione non si interrompe.
Funzione schedulata invocata nel weekend Check getUTCDay() === 0/6 → ritorno immediato con skipped: 'weekend'.
Nota già esistente in ore_mensili Il trigger usa DO UPDATE SET ore_q1=..., ore_q2=... — le note non vengono mai toccate.
ore_mensili mai esistita per quel mese Il trigger fa INSERT con note NULL — riga creata automaticamente.
daily_hours DELETE (riga eliminata) Trigger usa OLD per identificare mese, ricalcola da zero — ore_mensili si riduce correttamente.
DAILY_TOKEN_SECRET non configurato verifyToken lancia "DAILY_TOKEN_SECRET non configurato" — segnale chiaro di config mancante.
Concorrenza: due tab salvano contemporaneamente ON CONFLICT (risorsa_id, data) DO UPDATE è atomico in Postgres — vince l'ultimo.
